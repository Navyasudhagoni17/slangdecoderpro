# SlangDecoderPro 🗣️

**SlangDecoderPro** is a simple AI-powered application that helps users understand modern slang, abbreviations, and informal expressions by converting them into clear and simple language.

## ✨ Features

* 🔍 Decode slang words and phrases
* 💬 Convert informal expressions into simple language
* 🤖 AI/NLP-based slang interpretation
* ⚡ Simple and user-friendly interface
* 📚 Useful for understanding modern internet and social-media language

## 🛠️ Technologies Used

* Python
* Streamlit
* Natural Language Processing (NLP)
* AI/ML

## 📂 Project Structure

```text
slangdecoderpro/
│
├── app.py
├── requirements.txt
└── README.md
```

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Navyasudhagoni17/slangdecoderpro.git
```

Go to the project directory:

```bash
cd slangdecoderpro
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

```bash
streamlit run app.py
```

The application will open in your web browser.

## 💡 Example

**Input:**

```text
That movie was fire!
```

**Output:**

```text
That movie was excellent or very exciting.
```
